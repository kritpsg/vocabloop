📖 เจอคำที่ไม่รู้? คลุมแล้ว AI ทำการ์ดให้

วางประโยคหรือย่อหน้าภาษาอังกฤษที่คุณอ่านเจอ (ข่าว หนังสือ ข้อสอบ) กด "แสดงข้อความ" แล้ว แตะหรือลากคลุมคำที่ไม่รู้ คำที่แตะติดกันจะรวมเป็นวลีเดียว AI จะทำการ์ดโดยใช้ประโยคที่คุณเจอเป็นบริบท (ความหมายตรงกับตรงนั้น) และจัดให้ขึ้นเรียนก่อน

🤖 ให้ AI หาคำใหม่เอง (กดทีเดียว)

ไม่ต้องเลือกอะไร AI จะเลือกหัวข้อที่ยังไม่ได้เรียน ปรับความยากตามผลการเรียนของคุณ (ตอบถูกบ่อยแค่ไหน) หลีกเลี่ยงคำที่คุณมีแล้ว และเพิ่มเข้าคลังให้ทันที

สร้างชุดคำใหม่ด้วย Gemini

เลือกหัวข้อกับระดับ แล้วให้ AI คิดคำใหม่ที่ยังไม่มีในคลังของคุณ (พร้อมความหมายไทย ตัวอย่างประโยค คำเหมือน)

เติมข้อมูลจากคำที่คุณมีอยู่

วางรายการคำ (คั่นด้วยบรรทัดใหม่หรือเครื่องหมายจุลภาค) แล้วให้ AI ทำการ์ดให้ครบ

Gemini API

📊 ผลการอ่าน (.md)

ทุกครั้งที่ทำโจทย์อ่านเสร็จ ระบบจะสร้างไฟล์ผลลัพธ์ภาษาไทยเป็น Markdown (ผิดอะไร ควรทำซ้ำไหม คำศัพท์ที่ควรรู้) เลือกโฟลเดอร์ไว้ครั้งเดียว แล้วระบบจะเขียนไฟล์ให้เองทุกครั้ง พร้อมอัปเดต _overview.md (รายงานรวม) เหมาะกับการเอาไปให้ Claude/AI วิเคราะห์ต่อ

🔄 ซิงก์คอม ⇄ มือถืออัตโนมัติ

เก็บความคืบหน้า (การ์ด การทบทวน ประวัติ คอร์ส) ไว้ใน Gist ส่วนตัวของบัญชี GitHub คุณเอง ทุกเครื่องที่เปิดซิงก์จะดึง/รวม/อัปให้เองเมื่อเปิดแอปและหลังเรียนเสร็จ ไม่ทับกัน (Gemini key ไม่อัปขึ้นคลาวด์) การตั้งค่าบางอย่าง เช่น เสียง/จำนวนคำใหม่ต่อวัน แยกกันแต่ละเครื่อง

  1. เปิด หน้าสร้างโทเคน GitHub (ติ๊กไว้แค่ gist อย่างเดียว) เลือกวันหมดอายุตามต้องการ แล้วกด Generate token
  2. คัดลอกโทเคน (ขึ้นต้น ghp_) มาวางที่ช่องด้านล่าง แล้วกดเปิดซิงก์
  3. ที่เครื่องอื่น: ใช้ปุ่ม "สร้างลิงก์ย้ายเครื่อง" ด้านล่าง (ติ๊กรวม key/โทเคน) เปิดลิงก์ครั้งเดียวก็ซิงก์เองได้เลย

Gemini key ไม่ถูกอัปขึ้นคลาวด์ (เคยทำ แล้ว Google สแกนเจอแล้วเพิกถอน key) ใช้ "สร้างลิงก์ย้ายเครื่อง" ด้านล่างเพื่อพา key ไปอีกเครื่อง

โทเคนมีสิทธิ์แค่ Gist ใครได้โทเคนไปอ่าน/แก้ Gist ของคุณได้ จึงอย่าส่งต่อ ถ้าหลุดให้ลบโทเคนที่ github.com/settings/tokens

📱 ย้ายไปอีกเครื่อง (ไม่ต้องใส่ key ใหม่)

สร้างลิงก์ แล้วเปิดในมือถือ/คอมอีกเครื่อง แอปจะถามยืนยันแล้วนำ Gemini key กับการ์ดมาให้เลย ลิงก์นี้ มี key ของคุณอยู่ข้างใน ใครได้ลิงก์ก็ใช้ key ได้ ส่งให้ตัวเองเท่านั้น (เช่น ข้อความหาตัวเอง/โน้ตส่วนตัว) แล้วลบข้อความทิ้งหลังใช้ ถ้าหลุดให้ไปสร้าง key ใหม่ที่ Google AI Studio

เครื่องปลายทางต้องเปิดผ่านลิงก์ของเว็บ (https) แล้วเลือกนำเข้า ข้อมูลสองเครื่องจะ ไม่ซิงก์ต่อเนื่อง ต้องกดย้ายใหม่เมื่ออยากอัปเดตอีกเครื่อง
